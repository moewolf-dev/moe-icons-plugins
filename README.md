# Moe Icons for VS Code

Code completion, semantic highlighting and icon diagnostics for Moe Icons in
React and Vue projects.

- [Official website](https://moeicons.com/)
- [Documentation](https://moeicons.com/docs/)
- [CLI installation and usage](https://moeicons.com/docs/cli.html)
- [CLI repository and reference](https://github.com/moewolf-dev/moe-icons-cli#readme)

## Required: install the Moe Icons CLI

**You must install the Moe Icons CLI and use it to install and generate your
project's icons before using this extension's project-aware features.** The
extension reads the CLI-generated catalog and modules; installing the VS Code
extension alone does not install the icon library.

With Node.js 22 or newer, run these commands from your project's root:

```bash
npm install -D @moewolf/moe-icons-cli
npx moeicons init
```

Choose the React or Vue target and the icons/themes you need in
`moeicons.config.jsonc`, then install and generate:

```bash
npx moeicons install free
npx moeicons generate
```

For Pro installation, authentication and further configuration, see the
[CLI documentation](https://moeicons.com/docs/cli.html).

## Usage

Import components from the output directory generated by the CLI. For example,
if your configured output directory is `moeicons` beside the current file:

```tsx
import * as Icons from './moeicons';
const icon = <Icons.Archive />;
// Type <Icons.Ar to complete an installed export, if Archive was generated.
```

Completion, highlighting and diagnostics use the current project's verified
CLI-managed exports. Keep generated files consistent with
`.moeicons/install-metadata.json`; regenerate through the CLI when changing your
icon selection. The extension completes icon names without embedding SVG source
or downloading icon resources.

## Features and current scope

- Complete imported icon components and namespace members in React and Vue.
- Highlight recognized icon references with colors that follow the editor theme.
- Report unavailable exports in verified generated modules.
- Inspect style libraries and the plugin/library version map.

This is an early release. Relative imports from CLI-generated modules are
supported; automatic imports, npm/path-alias import resolution and Assets
reference completion are still in development. Dynamic or unverified inputs are
skipped. The bundled legacy catalog maps to resource version 0.0.17; it does not
replace the project's installed catalog. Account features await production
endpoint rollout and validation.

## Settings

| Setting | Default | Description |
| --- | --- | --- |
| `moeicons.highlightColorMode` | `auto` | Follow the editor theme, or force `light` / `dark` semantic-token modifiers. Override colors in `editor.semanticTokenColorCustomizations`. |
| `moeicons.styleGroup` | `outline` | Style library used for completion/highlighting. |
| `moeicons.libraryVersion` | `""` | Library version to match (empty = latest bundled). |
| `moeicons.websiteUrl` | `https://moeicons.com` | Official website link. |
| `moeicons.repositoryUrl` | `https://github.com/moewolf-dev/moe-icons` | Public repo link. |
| `moeicons.pluginRepositoryUrl` | `https://github.com/moewolf-dev/moe-icons-plugins` | Plugin repo link. |
| `moeicons.documentationUrl` | `https://moeicons.com/docs/` | Official documentation link. |

## Commands

- `Moe Icons: List Style Libraries` — list style libraries with `free`/`pro` markers.
- `Moe Icons: Show Plugin/Library Version Map` — show the 1:1 version mapping.
- `Moe Icons: Show Account` — focus the account/version view.
- `Moe Icons: Refresh Account` — read the current CLI session and refresh entitlement status.

## Development

```bash
npm install
npm run compile   # type-check
npm run build     # bundle to dist/
npm test          # unit tests
npm run test:core-host # isolated local VS Code core smoke test
npm run package   # produce a .vsix
```

Press `F5` in VS Code to launch an Extension Development Host.


## Marketplace publishing

Publisher: `moewolf`; extension ID: `moewolf.moe-icons-plugins`.
Development and packaging require Node.js 22 or newer.

release workflow. Marketplace OIDC currently returns `Trusted Publishing is not
supported`; use the reviewed VSIX for manual Marketplace upload until a supported
