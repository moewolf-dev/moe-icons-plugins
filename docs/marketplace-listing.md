## Short description

Code completion, semantic highlighting and icon diagnostics for Moe Icons
React and Vue projects generated by the Moeicons CLI.

## Requirements block

- **VS Code 1.85 or newer.** The extension runs in the VS Code Extension Host;
  you do **not** need to install Node.js to use the extension.
- **Moeicons CLI users need Node.js 24 or newer** in the terminal where the CLI
  runs.
- Install the CLI and generate the project before using project-aware features:

  ```bash
  node -v   # v24.x or newer
  npm install -D @moewolf/moe-icons-cli
  npx moeicons init
  npx moeicons install free
  npx moeicons generate
  ```

## Feature bullets

- Complete verified icon exports in React, Vue and JSX/TSX files.
- Highlight recognized icon references using editor-theme-aware semantic tokens.
- Diagnose missing exports and malformed usage with `MOE-ICON-*` codes.
- Show the installed resource, CLI and project contract versions.
- Read the CLI session read-only and explain Free/Pro entitlement without
  guessing.
- Show project recovery steps for a missing/old CLI, ungenerated projects,
  invalid metadata, schema drift and stale generated files.
- Keep troubleshooting output redacted and opt-in.

## Runtime and privacy notes

The extension does not install the CLI, run terminal commands, download icon
resources or copy account tokens. It reads `.moeicons` project metadata and the
CLI session store on the extension host. Remote SSH, WSL and container windows
use that host's credential store; local credentials are not forwarded.
`moeicons.enableDiagnosticOutput` is off by default; the output channel never
contains tokens, email addresses, authorization headers, session JSON, absolute
home paths, icon source or network bodies.
